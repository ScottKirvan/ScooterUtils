# Scooter Utilities Overview

An overview of Scooter Utilities, a collection of quality-of-life editor tools and Blueprint nodes for Unreal Engine.

**Scooter Utilities** is an Unreal Engine plugin that bundles essential quality-of-life tools for artists and developers. Quickly navigate to your project on disk, restart the editor with a single click, and keep important settings persistent between editor sessions.

Think of it as a Swiss Army Knife of tools that make Unreal Engine a bit quicker to use, especially if you're creating and maintaining several projects. If there's something you find yourself turning on or resetting every time you open a project, it might be a good candidate for Scooter Utilities, so feel free to [make a suggestion](https://github.com/ScottKirvan/ScooterUtils/issues/new?labels=enhancement&title=%5BFEATURE+REQUEST%5D).

## Features

* A **toolbar dropdown button** in the Level Editor for quick access to plugin tools and settings.
* **Restart the editor** from the **File** menu or the toolbar, with no hunting for your `.uproject` file.
* A **customizable hotkey** for restarting the editor (default: **Ctrl + Shift + Alt + R**).
* **Open your project folder** in your file browser with one click.
* **Adjust the editor interface scale** for comfortable viewing or presentations, and keep it across every project.
* **Set a persistent maximum FPS** that survives editor restarts.
* **Keep the viewport FPS display enabled** across sessions.
* **Blueprint nodes** for JSON, file IO, config access, debug logging, Blueprint reflection, and placeholder text.

## Supported Engine Versions

Scooter Utilities supports **Unreal Engine 5.5 through 5.8** on Windows, macOS, and Linux. The Blueprint node library also runs on Android.

## Contributing

Got a cool tool or feature idea? Found a bug? Want to help with documentation? Contributions are welcome.

You don't need to know GitHub to help. Just follow these links:

* [Report a bug](https://github.com/ScottKirvan/ScooterUtils/issues/new?labels=bug&title=%5BBUG%5D)
* [Request a feature](https://github.com/ScottKirvan/ScooterUtils/issues/new?labels=enhancement&title=%5BFEATURE+REQUEST%5D)

If you'd like to contribute code or documentation directly, check the [issues](https://github.com/ScottKirvan/ScooterUtils/issues) page for something to tackle, [grab a fork](https://github.com/ScottKirvan/ScooterUtils/fork), and submit a [pull request](https://github.com/ScottKirvan/ScooterUtils/pulls). See the [repository README](https://github.com/ScottKirvan/ScooterUtils#readme) for developer details.
